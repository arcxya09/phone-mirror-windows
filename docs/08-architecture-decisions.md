# 08 架构决策记录

状态定义：**采用**表示本版设计选择；**验证门槛**表示必须先有实际证据；均不表示已写出功能代码。

## ADR-001：scrcpy + 安全无线调试

采用。用户接受首次开启无线调试并配对。复用画面、声音和输入能力；入口在电脑端。代价是不能从手机原生 Miracast/AirPlay 菜单发起连接，也不支持 iPhone。首版不添加第二套接收协议。[R1][R2]

## ADR-002：独立原生窗口

采用。不重写私有媒体协议，不把视频帧绕经 WinUI 图片控件，也不依赖跨进程窗口嵌入。代价是需要处理管理窗口、工具区和原生视频的焦点与主题一致性。M0 对工具区承载做技术验证，结论记录为补充 ADR。[R4]

## ADR-003：定制引擎而非只做启动器

采用。IPC、无干扰中文输入、结构化结果、焦点释放和禁用拖放都需要明确代码路径。只启动未经修改的 scrcpy 不能满足完整产品要求。采用固定标签上的小补丁集，控制维护成本。[R5][R15]

## ADR-004：鼠标 SDK，键盘 UHID

采用。鼠标保留绝对定位和可自由移出窗口的体验；键盘由手机输入法处理实体按键。代价是 OEM 权限与输入法兼容性需要测试。AOA 不是无线后备。[R3][R12]

## ADR-005：电脑中文通过显式文字面板

采用。不保存输入历史，不改写 Windows 剪贴板，直接通过本地 IPC 将正文交给引擎。手机剪贴板被修改属于明确副作用。禁止使用逐字键码作为中文通用降级。[R3][R5]

## ADR-006：不自动重放输入

采用。所有输入只属于当前会话；文字序号单调、防重复。传输状态未知时让用户检查手机。代价是某些断线后用户需要手工判断重试，但避免重复消息和错框插入。无法得到 App 内成功回执时，不宣传端到端 exactly-once。

## ADR-007：私有 ADB 与凭据目录

采用且为 M0 验证门槛。防止结束其他开发工具的 ADB、共享全局密钥和跨项目配置污染。独立端口不构成完整本地安全沙箱；本地恶意进程风险必须披露。单设 ADB_VENDOR_KEYS 不等于完整密钥隔离。[R9][R11][R16]

## ADR-008：能力检测优先于旧教程

采用。当前 37.0.1 已移除 openscreen；发现后端、track-services 格式和实际环境变量要按锁定版本验证。保留有界后备，禁止遇错循环切换全局环境。[R8]

## ADR-009：仅观看具有完整行为边界

采用。限制键鼠、剪贴板、手机屏幕电源和手机设置入口；桌面播放静音和窗口功能可保留。允许以重新启动 `--no-control` 实现确定性。此模式不收窄 ADB 调试授权。[R5]

## ADR-010：内容不落盘，无自动跨设备剪贴板同步

采用。没有账号、遥测和云服务。只记录最小技术诊断。代价是某些故障需要用户提供非敏感复现，不能靠全量日志回放；不能承诺阻止 OS 分页或管理员级采集。

## ADR-011：首次版本锁与许可证决策先于二进制发布

采用。候选版本不等于已测试版本；原创许可证不从另一项目继承。上游许可证分别保留，公开仓库不冒充开放授权。用户未选择原创许可证前不代为授权。[R14][R17]

## ADR-012：范围收敛

采用。首版只做 Android 单设备局域网投屏与输入。不做文件管理、APK 安装、录屏、自动更新和云端远控。隐藏按钮不能替代禁用上游已存在的文件拖放路径。
