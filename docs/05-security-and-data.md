# 05 安全、隐私、数据与诊断

## 1. 信任边界

只连接用户拥有或获得明确授权的手机；首次配对由手机用户开启无线调试并提供配对码。程序不绕过手机锁屏、设备管理策略、屏幕保护、支付页面或禁止捕获的内容。

ADB 具有 shell、安装和调试等能力；即使本产品只暴露投屏按钮，电脑持有的调试授权仍然广于投屏。关闭本应用或切到只读不等于在手机端撤销授权。[R2] 来源见[参考资料](09-references.md)。

Android 安全窗口可能阻止捕获。黑屏也可能由编码、窗口尺寸或传输故障引起，不能仅凭黑色画面推断使用了 FLAG_SECURE；只给出适用的可能原因和诊断证据。[R13]

## 2. 威胁与对策

| 威胁 | 对策 | 残余边界 |
| --- | --- | --- |
| 局域网伪造设备名 | 广播不构成信任；用户配对、认证后绑定身份 | 同名设备仍需选择 |
| 私钥被打包/导出 | 独立目录、ACL、导出白名单、提交前扫描 | 本用户恶意程序和管理员不能完全防御 |
| 误连其他设备 | 固定 selector、session/generation 核验 | 不可靠标识时由用户确认 |
| 命令注入 | 路径固定、参数数组、端点解析；不传任意 shell | 引擎及 ADB 自身仍需更新审查 |
| IPC 被误用 | 本地管道 ACL、拒远程、PID 验证、方法白名单 | 不声称隔离同用户完全受控进程 |
| ADB 端口暴露 | 仅回环监听，禁止 `-a`、公网映射 | 本地回环 TCP 不具备用户身份认证 |
| 私密内容泄漏 | 不截图、不记录正文、无遥测、显式粘贴 | 手机剪贴板与 OS 机制由用户知悉 |
| 输入重复或错投 | 单会话、输入序号、防重、失焦释放 | 无远端 App 内成功证明 |
| 后台继续控制 | 锁定/退出停止、Job Object、自有进程归属 | 网络中断下远端清理为尽力执行 |
| 拖入恶意文件 | 禁止文件 drop/push/install | 不能把隐藏入口当作功能禁用 |

## 3. 网络与运行权限

运行不要求管理员权限，不安装系统服务，不建立云中继。不启用传统 `adb tcpip 5555` 后备，不自动打开 USB 调试或修改手机系统属性。

允许 mDNS 局域网发现与指定目标无线调试连接；scrcpy 的媒体端口保持通过受控 ADB 通道处理，禁止实现为未认证的局域网公开视频服务器。[R4][R7]

防火墙提示应说明具体组件与用途，限定合理网络范围。禁止推荐关闭整个防火墙、关闭系统安全功能、允许任意程序对公网监听。

首次安装后运行时无需互联网；首次获取依赖、手动下载新版本或发布 GitHub 文档属于单独的网络行为，不混同正常投屏。

## 4. 本地存储

规划目录：

```text
%LOCALAPPDATA%\PhoneMirrorWindows\
  config\settings.json
  config\devices.json
  config\settings.previous.json
  adb-profile\                  # 密钥与本应用的 ADB 状态
  logs\                        # 已脱敏的轮转事件
  runtime\                     # 本地实例/会话元数据，无内容
```

便携版把可执行文件放在解压目录，默认仍将敏感状态放在当前用户 LocalAppData，不把 adbkey 放在 U 盘或共享安装目录。该选择是安全默认，不能宣传成“所有数据随文件夹移动”。

目录 ACL 只授予当前用户、SYSTEM 及必要管理主体；继承权限必须检查。ADB 所需密钥格式由上游决定，本版不宣称密钥已由 DPAPI 加密；需要明文提供给 ADB 的密钥至少用文件 ACL、严格位置和备份排除保护。

绝不读取其他项目或全局 `.android` 的既有配对密钥，不把用户旧授权导入本应用。

### 4.1 数据分类与保留

| 数据 | 处理位置 | 保留策略 |
| --- | --- | --- |
| 视频帧、音频样本 | 引擎内存 | 播放后释放；不落盘 |
| 键鼠事件 | 内存短队列 | 发送或失焦/断线即丢弃 |
| 面板正文、显式粘贴文本 | 内存 | 结束/关闭后清理，不作历史 |
| 配对码 | 配对进程输入 | 完成/失败/取消后清理 |
| ADB 私钥与信任数据 | 专用目录 | 到用户清除为止，禁导出 |
| 设备别名和偏好 | 配置目录 | 到用户删除为止 |
| 非敏感诊断事件 | 日志目录 | 总量 20 MiB，最长 7 天，先到先删 |

不承诺对操作系统分页、第三方终端监控或系统级转储进行不可恢复擦除。应用不主动生成包含内容的内存转储，隐私声明限定为应用自身的采集和存储行为。

## 5. 剪贴板政策

默认关闭上游自动同步，禁止后台轮询任何一端剪贴板。电脑 Ctrl+V 或面板按钮属于显式传输动作，只读取当次需要的纯文本，不获取图像、文件列表、HTML 富文本和历史记录。

面板插入不改写 Windows 剪贴板；会修改手机剪贴板。不得自动还原手机旧内容：读取旧内容本身超出本次最小化操作，而且可能覆盖用户随后复制的新内容。[R5]

提示用户不要通过该通道输入密码、密钥和一次性验证码。软件不能可靠识别所有安全字段或保证第三方输入法不读取剪贴板。

## 6. 诊断事件

只允许序列化已定义字段：UTC 时间、程序版本、事件 ID、阶段、耗时、重试次数、错误码、视频参数、内存区间和设备匿名标识。

设备匿名标识采用每次导出独立随机别名，不在跨用户或跨导出间建立可追踪标签。IP、主机名、序列号、Wi-Fi 名称和 Windows 用户路径在导出中删除或替换。

禁止正文、屏幕、音频、密钥、配对码、原始剪贴板内容、完整命令行、原始手机 logcat、完整 ADB TRACE 或整个 `.android` 目录。第三方 stderr 不能原样持久化；先分类并脱敏，无法保证安全的片段直接丢弃。

UI 的错误详情可以显示用户当前明确输入的端点帮助排查，但导出仍须脱敏。只有显式勾选且预览确认后才允许附加非敏感环境信息；首版不实现敏感附件选项。

## 7. 错误分类

| 错误码 | 已知含义 | 界面动作 |
| --- | --- | --- |
| DEPENDENCY_MISSING | 固定路径依赖不存在 | 重新安装/校验，不临时下载未知文件 |
| DEPENDENCY_MISMATCH | 版本或摘要不匹配 | 停止启动 |
| ADB_START_FAILED | 本应用 ADB 未就绪 | 导出诊断，不杀全局 ADB |
| DISCOVERY_EMPTY | 当前无符合条件广播 | 检查无线调试，提供手动入口 |
| PAIRING_INVALID | 配对操作返回无效/失效码 | 重新读取手机配对码 |
| PAIRING_TIMEOUT | 配对请求超时 | 保留可取消/重试入口 |
| TRANSPORT_AUTH_FAILED | 设备认证失败 | 提示检查手机授权 |
| TRANSPORT_UNREACHABLE | 指定端点未连通 | 检查正确端口和局域网 |
| FIRST_FRAME_TIMEOUT | 已启动但未得到首帧 | 查看采集/编码诊断 |
| INPUT_PERMISSION_DENIED | 有明确注入权限错误 | 禁用相关控制、保留画面 |
| UHID_UNAVAILABLE | UHID 初始化失败 | 手机输入设置或兼容模式 |
| AUDIO_UNAVAILABLE | 音频流不可用 | 继续视频，只提示一次 |
| TEXT_TOO_LARGE | UTF-8/IPC 字节超限 | 不发送，不截断 |
| TEXT_DELIVERY_UNKNOWN | 请求发出后失去确认 | 提示检查手机，禁止自动重发 |
| IPC_PROTOCOL_MISMATCH | 本地协议不兼容 | 拒绝本次引擎 |
| SESSION_CANCELLED | 用户主动取消 | 不展示为故障，不重连 |
| RECONNECT_EXPIRED | 恢复预算耗尽 | 停止重试，显示按钮 |

错误分类依赖可验证的上游错误或本地阶段，不为未知故障伪造原因。用户消息和日志字段分别维护，避免把长堆栈当正文。

## 8. 供应链、发布和支持

只使用官方来源及经核验的固定依赖。发布前记录逐文件摘要、上游标签和补丁集；摘要来源与独立下载校验状态分开，不能把从网页抄来的 SHA256 宣称为本地验证通过。

本项目原创许可证由仓库所有者决定；公开仓库不自动等于允许任意商业使用。scrcpy 的 Apache-2.0 及所有打包组件各自义务必须保留，不将产品许可证覆盖上游代码。法律与分发审核未完成前不发布二进制。[R14][R17]

安全问题公开报告只提交最小非敏感复现。当前没有已启用的私密报告渠道，因此 SECURITY 文档不得编造邮箱、服务时限或声称 GitHub 私密报告已开启。
