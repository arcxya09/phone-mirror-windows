# 06 测试计划与验收标准

**当前执行状态：以下真机、Windows 和性能测试均未执行。** 本文规定应如何证明软件可用；文档检查和 Schema 检查不替代这些测试。

## 1. 测试环境与覆盖

Windows：至少 Windows 10 22H2 x64 一台、Windows 11 x64 一台；保存实际构建号、CPU、内存、GPU、驱动、运行时和产品依赖锁版本。正常用户运行、无开发 SDK 的干净安装环境必须覆盖。系统支持状态与本应用技术兼容性分别记录，不将“能运行”作为操作系统仍受安全支持的声明。

手机：优先覆盖 Android 11、Android 13–16 中的代表机型；增加可获得的最新 Android 版本。至少三种 OEM 系统，其中包含一台具有额外输入安全开关的机型。每项记录具体型号、系统构建、输入法版本；没有测试过的品牌/系统组合不写成已支持。Android 17 的新无线发现能力另设记录，不替代 Android 11 基础回归。[R1][R2]

网络：电脑有线+手机 Wi-Fi、双方 Wi-Fi、5 GHz 与 2.4 GHz、访客隔离、mDNS 被阻断但单播可达、VPN/多网卡、IPv4/IPv6。首轮性能基准使用正常 5 GHz 局域网，AP 端无明显拥塞；记录信号与往返时延。

输入法：Windows 微软拼音以及至少一种常见第三方输入法；手机自带输入法和至少一种支持实体键盘的输入法。模拟器可验证解析与状态机，但不能证明无线真机和 OEM 注入权限兼容。

## 2. 量化目标与测量口径

所有数值是工程验收目标，首次测量后由问题记录解释是否达标；未达标不能通过更换口径隐藏。

| 指标 | 初始目标 | 测量口径 |
| --- | --- | --- |
| 已配对可达设备连接成功率 | 每个基准组合至少 29/30 次 | 失败计入分母；不包含人为禁止网络/授权的负向用例 |
| 已发现设备的连接到首帧 | P95 ≤ 5 秒 | 从点击连接到实际绘出首帧；发现和首次配对单独计时 |
| 首次发现 | P95 ≤ 8 秒 | 手机开始广播且网络正常时到候选可见 |
| 交互端到端延迟 | P95 ≤ 180 ms | 240 fps 摄影或同等测量，记录手机/电脑动作；至少 100 次样本 |
| 2 小时稳定性 | 无崩溃、无持续内存增长 | 混合静态、滚动和音视频；不把静态低帧率当作丢帧 |
| 连续媒体音画偏差 | P95 绝对值 ≤ 120 ms | 自制闪光/声音同步测试源；不使用敏感用户内容 |
| 空闲资源 | 平均 CPU ≤ 1%，自有进程工作集 ≤ 180 MiB | 规定测试机、10 分钟稳定窗口，CPU 按全机归一 |
| 均衡投屏内存 | 自有进程工作集 ≤ 500 MiB | 1920 上限/60 fps 上限；记录实际流与设备温度 |
| 正常退出 | 3 秒内自有投屏进程停止 | 手机端异常网络清理单独记录，不能虚报即时保证 |
| 错投/自动重复文本 | 0 次 | 所有文本和竞态用例；发现一次即阻断发布 |
| 敏感日志、静默 APK 安装 | 0 次 | 白名单导出与拖放负向测试；发现一次即阻断发布 |

不引用上游宣传的最低延迟作为本软件的实测成绩。帧率上限不是实际帧率：静态屏幕、新内容帧和视频帧率分别看待。[R6]

## 3. 功能用例

### 连接与生命周期

| ID | 测试 | 操作/条件 | 预期结果 |
| --- | --- | --- | --- |
| C01 | 首次配对 | 清除本应用配对；手机打开配对码页；选择设备并输入正确码 | 无需 USB；配对与连接状态分别显示 |
| C02 | 错误配对码 | 输入六位错误码 | 失败有明确提示；不保存码；不创建可信设备 |
| C03 | 配对码到期 | 等手机配对码失效后提交 | 不假成功；允许重新读取码 |
| C04 | 手动配对 | 阻断广播但保持点对点可达，手填配对端口 | 配对可完成；随后独立读取连接端口 |
| C05 | 端口混淆 | 用配对端口发起连接 | 说明端点问题，不反复要求重新配对 |
| C06 | 取消配对 | 提交后立即取消；模拟成功回调迟到 | 不自动开窗口；提示远端授权可能仍存在 |
| C07 | 恶意广播 | 注入超长/控制字符名称、非法端口和同名设备 | 不崩溃、不注入命令、不自动信任 |
| C08 | 特殊地址 | IPv4、带 scope 的 IPv6、空格及非法地址 | 正确解析有效值；发送前拒绝非法值 |
| C09 | 重新启动连接 | 保持配对记录，退出并启动软件 | 无需重复配对；不默认自动投屏 |
| C10 | 端口变化 | 关闭再开启手机无线调试 | 重新发现连接端口，不绑定旧端口 |
| C11 | 地址变化 | 切换 DHCP 地址后重新发现 | 先认证再绑定，不按旧 IP 认定身份 |
| C12 | 同型号多手机 | 两台同型号已配对手机同时上线 | 只连接用户指定目标 |
| C13 | 授权撤销 | 手机删除电脑配对后连接 | 认证失败；不明文降级、不重配他机 |
| C14 | 访客网络隔离 | 手机与电脑同 SSID 但终端隔离 | 可解释连接失败，手动地址不承诺绕过隔离 |
| C15 | ADB 共存 | Android Studio/其他 scrcpy 运行时启动本软件 | 不结束它们的 ADB、不改变全局密钥和配置 |
| C16 | 发现组件差异 | 对新旧输出格式及缺失命令运行解析测试 | 能力检测和后备有效，不硬编码旧 openscreen |
| C17 | 短暂断网 | 活动会话断网 5 秒后恢复 | 30 秒内只尝试原设备；不重放键鼠/文本 |
| C18 | 长时间断网 | 断网超过 30 秒 | 自动恢复停止，出现手动重连 |
| C19 | 用户关闭 | 分别点击断开、关闭视频窗、退出主程序 | 行为符合规格，关闭后不重连 |
| C20 | 锁定与休眠 | Win+L、睡眠、切换 Windows 用户 | 停止声音和画面；恢复后不自动控制 |
| C21 | 进程异常 | 分别终止引擎和管理进程；制造 ADB 无响应 | 清理自有资源，不杀无关进程；可再次启动 |
| C22 | 异步竞态 | 连续连接/取消/重试 30 轮并延迟旧回调 | 始终最多一个活动会话，无幽灵窗口 |

## 4. 自动化层次

单元测试：地址解析、mDNS 输出适配、状态机、超时预算、取消代际、配置迁移、UTF-8 长度、输入序号、防重、日志脱敏与 IPC 帧解析。

组件测试：用假的 ADB 与引擎进程模拟退出码、迟到输出、超长 stderr、分片管道、断连和版本不一致；不要求手机。每个错误至少具有正向分类与无法分类的后备用例。

集成测试：Windows 真实进程、管道 ACL、Job Object、SDL/WinUI 焦点、文件系统 ACL、重复启动、干净安装和卸载。

真机测试：配对、无线转发、音频、OEM 权限和输入法。不能通过 Windows CI 上单纯编译成功替代。

## 5. 发布门槛

所有 FR 对应的关键流程通过；错投、重复插入、后台控制、密钥泄漏、自动安装和全局 ADB 被误杀问题为阻断项。主目标 Windows 与至少三种手机系统组合完成实测，兼容性清单精确到版本。

每个发布版本提交测试报告，列出 commit、依赖锁、设备矩阵、样本数、原始非敏感统计、失败与回归记录。未执行项用“未执行”标记，不填“通过”。计划支持与已验证支持分开。
