# 01 产品需求与交互设计

版本 0.1 / 2026-09-17。除已确认方向外，尺寸、时间和阈值均为本设计默认值。

## 1. 目标与范围

用户完成一次无线调试授权，以后在 Windows 上一键查看和操作手机。主要场景是桌面办公中查看消息、输入文字、浏览手机内容和演示手机界面。不将游戏级延迟、多点游戏操控、直播采集或企业批量管控作为首版承诺。

基本约束：手机免安装独立 App；无需 Root；日常连接不接 USB；不要求手机从原生“无线投屏”菜单寻找电脑；无账号、广告、云中转和内容分析。

scrcpy 的桌面显示与键鼠控制、Android 11+ 无线调试属于上游能力；完整产品体验仍需要封装和定制。[R1][R2]，来源统一见[参考资料](09-references.md)。

### 1.2 首版排除

iPhone、Miracast、AirPlay、Google Cast 接收；公网远程操作；扫描整个网段；USB 首次授权兼容旧手机；文件管理、APK 安装、录屏、截图落盘、麦克风、摄像头采集、多设备同屏、通知采集、OCR、AI 内容理解和自动更新。

首版不兼容没有 Android ADB 无线调试能力的系统。不能仅按手机品牌判定兼容，更不能将不同系统架构统称为可用 Android。

## 2. 首次使用

未添加设备时：

```text
手机同屏                             设置

              将手机连接到电脑
        首次需要开启手机的无线调试

                  添加手机
```

点击“添加手机”后显示三个步骤：连接同一可互通的局域网；手机打开开发者选项中的无线调试；选择“使用配对码配对设备”。引导允许复制文字，不需要登录或浏览器参与运行。

自动发现成功时显示候选手机及当前地址，设备名可能来自未经认证的局域网广播，不能显示“可信”标记。用户选择后输入六位数字配对码，点击“配对”。输入框禁止自动补全和持久化。

手动模式要求“配对地址”和配对码；配对后未找到连接端口，另行提示在无线调试首页读取“连接地址”。字段必须清楚区分，禁止要求用户反复尝试同一端口。详细流程见[连接设计](03-wireless-connection.md)。

成功后显示“配对完成”和“连接”。首次进入投屏前提示：仅对自己拥有或获授权的手机操作；配对授权具有超出投屏本身的调试能力。

取消行为：立即关闭当前配对请求；若手机已在取消前接受授权，提示可能需要在手机端删除配对，不能显示“授权已撤销”。

## 3. 日常连接

设备页参考尺寸为 420×300 DIP，最小 360×260 DIP。空状态只显示添加按钮；存在记录时，最近设备置顶。多个记录采用紧凑列表，不使用侧栏。

设备卡片显示用户自定义名称、简短状态和单一主动作。底层状态可为“已配对，正在查找”“发现设备”“正在连接”“正在启动画面”“连接失败”；只有认证和设备确认后才显示“已连接”。

默认不自动进入投屏。设置项“启动时连接上次设备”可由用户开启；即使开启，Windows 解锁、休眠恢复和网络信任变化后也不自动恢复控制。

连接中必须能取消。连点只产生一个连接任务；取消后迟到的回调不得重新打开窗口。

## 4. 投屏窗口

### 4.1 主体

原生视频窗口是唯一主工作窗口；管理页隐藏但控制进程存活。标题显示手机别名；保留标准拖动、缩放、最小化、最大化、关闭行为。不同窗口必须使用一致的产品名称和图标，避免用户误认为两个无关程序。

图像保持比例，禁止为了填满窗口拉伸手机画面。黑边不作为可点击手机区域。旋转时依据新帧尺寸重新布局，保留可见位置；用户主动调整的大小优先。

起始尺寸以当前显示器工作区为限；首次按竖屏高度不超过工作区 85% 计算。所有持久化位置以 DIP 和显示器标识记录，恢复时重新换算物理像素。

### 4.2 操作区

顶部工具区含“输入文字”“全屏”“更多”。鼠标进入顶边或键盘焦点进入时显示；指针离开且未操作 1.2 秒后隐藏。菜单展开、键盘导航和拖动期间不得隐藏。按钮命中区域至少 32×32 DIP，提供文字提示与无障碍名称。

M0/M1 可以采用系统标题栏和快捷键验证；M2 才接入完整工具区。工具区的点击应在桌面层消费，不得落到手机视频对应位置。实现方式见[架构设计](02-architecture.md)。

“更多”菜单：声音开关、窗口置顶、仅观看、画质、关闭/恢复手机显示屏、断开。为避免过度承诺，音频源或键盘模式等需要重启会话的设置，明确提示并只在用户确认应用后重新启动。

“关闭手机显示屏”默认关闭，不等同于解除或绕过手机锁屏。具体设备可能在锁定状态下限制控制或采集；该能力不是登录或解锁替代品。[R6]

### 4.3 关闭和系统事件

关闭投屏窗口：停止会话、释放按键、关闭音视频连接、返回设备页。

关闭设备页：退出整个应用，停止本应用自有进程。设置页关闭只关闭设置页。

Windows 锁定、休眠或切换用户：清空待发送输入、停止投屏、隐藏敏感画面并停止声音。恢复后显示“已暂停，请重新连接”。不能在解锁后静默接管手机。

短暂断网：显示断线状态并立即禁止输入；只有原设备会话可以在有限预算内重连。恢复后不抢其他 Windows 应用焦点。

## 5. 键鼠和中文入口

普通鼠标使用 SDK 绝对坐标模式；右键返回，中键桌面。只有视频窗口实际获得焦点后，键盘才发送到手机。任何菜单、文字面板或 Windows 其他应用获得焦点时，终止转发并释放已经按下的键。

手机输入法路径：UHID 让手机识别外接实体键盘，中文组词由手机输入法处理。电脑输入法路径：在本地面板完成编辑，仅发送确认后的 Unicode 文本。[R3]

面板建议初始 480×200 DIP，支持多行，显示 UTF-8 字节上限；默认上限 16 KiB。Enter 在面板中换行；插入只由按钮触发。首版不设置容易与中文候选确认冲突的全局插入快捷键。

“插入”只请求将文字粘贴到当前手机输入框，不自动按 Enter、不发送聊天消息。没有可靠方法证明远端输入框当前状态，因此面板要求用户先点选手机输入框，结果提示区分“请求已发送”和“结果未确认”。

## 6. 设置页

只保留连接、画面与声音、输入、设备与诊断四组；使用单页可滚动内容，不增加多层导航。

连接：启动时连接上次设备（关）；设备记录管理。

画面与声音：流畅/均衡/清晰；电脑声音（开）；置顶（关）。

输入：可控制/仅观看；默认 UHID；实体键盘设置入口；剪贴板策略说明。不提供自动跨设备剪贴板同步开关，首版固定关闭。

设备与诊断：删除本地记录；手机端撤销授权说明；导出脱敏诊断；版本及第三方声明。

高级编码器、ADB 地址和环境变量不进入普通设置。手动地址仅在添加/连接故障流程提供。

## 7. 视觉、可访问性和用语

使用系统字体、系统明暗主题；正文 13–14 DIP；标题 16–18 DIP；避免字体光栅化后缩放。视频区域不使用模糊或半透明处理。动画建议 120–180 ms，并服从系统减少动画设置。

Windows 10 无法提供的装饰使用纯色后备，不影响核心操作。键盘 Tab 顺序遵循视觉顺序，主按钮、错误说明和设备状态可被屏幕阅读器读取。

提示应描述已检测到的事实，例如“配对码无效，请重新读取手机上的配对码”“设备未响应，请检查无线调试和网络”。无证据时不得归因为“手机权限未开启”或“路由器阻止了投屏”。

全部界面状态以中文为首版语言，不出现堆栈、原始 ADB 输出、长串端口参数和不必要的省略号。
